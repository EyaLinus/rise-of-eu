# Music

All tracks in this folder are generated by `tools/gen_music.py` from scratch: no samples, no
recordings, no third-party audio. They are part of this project and carry no extra licence
or attribution requirement. Regenerate with `python3 tools/gen_music.py` (needs numpy and
ffmpeg with libvorbis); the same seeds give the same tracks.

| File | Mood | Mode, tempo |
|---|---|---|
| hof_im_fruehling.ogg | peace | D dorian, 84 bpm, 3/4, recorder + lute |
| pilgerweg.ogg | peace | A aeolian, 66 bpm, harp |
| markttag.ogg | peace | G mixolydian, 104 bpm, 3/4, recorder + lute + drum |
| abendlaute.ogg | peace | C major, 72 bpm, lute + harp |
| heerzug.ogg | war | E phrygian, 92 bpm, low recorder + drum |
| belagerung.ogg | war | D aeolian, 76 bpm, harp + lute + drum |

`scripts/ui/music.gd` plays peace tracks, and war tracks while the player is at war.
To add real recordings later, drop an OGG here and list it in `Music.TRACKS` (check its licence first).
